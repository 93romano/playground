# 1단계: Page 클래스 - 데이터베이스의 기본 단위

## 🏠 데이터베이스를 아파트로 생각해보세요!

### 왜 "페이지"가 필요할까요?

아파트를 지을 때 방을 모두 다른 크기로 만들면 어떨까요? 관리하기 어렵겠죠. 데이터베이스도 마찬가지입니다.

**페이지 = 똑같은 크기의 방**
- 모든 방(페이지)이 **4KB로 동일**
- 데이터를 저장할 때 이 방 하나씩 사용
- 방 번호(`page_id`)로 구분

## 📦 실생활로 비유하면:

### 1. 택배 상자를 생각해보세요
```cpp
constexpr size_t PAGE_SIZE = 4096;  // 4KB = 표준 상자 크기
```
- 택배사가 모든 상자를 같은 크기로 만드는 이유와 같음
- 트럭에 효율적으로 적재하고, 관리하기 쉬움

### 2. 방 번호표
```cpp
page_id_t page_id_;  // "101호", "102호" 같은 방 번호
```

### 3. 방 안의 물건들
```cpp
std::vector<char> data_;  // 4KB 크기의 저장 공간
```
- 방 안에 가구, 물건들을 넣는 것처럼 데이터를 저장

## 🔍 각 코드가 왜 필요한가요?

### 4. 더러워진 방 체크
```cpp
bool is_dirty_{false};  // "이 방이 더러워졌나?"
```
**왜 필요할까요?**
- 방을 사용하다가 더럽혀지면 → 청소(저장)가 필요
- 깨끗한 방은 → 그냥 다른 사람이 써도 됨
- 메모리에서 데이터를 바꾸면 `is_dirty_ = true` → 나중에 디스크에 저장 필요

### 5. 생성자의 역할
```cpp
Page::Page(page_id_t page_id) : page_id_(page_id), data_(PAGE_SIZE, 0)
```
**쉽게 말하면:**
- 새 방을 만들 때: 방 번호를 붙이고, 4KB 크기로 깨끗하게 청소해둠
- `data_(PAGE_SIZE, 0)` = 방 안을 모두 0으로 초기화 (완전히 비운 상태)

## 💡 핵심 포인트

이 `Page` 클래스는 데이터베이스의 **가장 기본 단위**입니다:

1. **표준화**: 모든 데이터를 4KB 단위로 관리
2. **효율성**: 디스크 읽기/쓰기가 페이지 단위로 이루어짐  
3. **추상화**: 복잡한 메모리 관리를 간단한 "방" 개념으로 단순화

마치 아파트 관리사무소에서 모든 방을 똑같은 크기로 만들어서 효율적으로 관리하는 것과 같습니다!
