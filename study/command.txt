2.3.3. Schemas (스키마)
스키마는 테이블, 데이터 타입, 함수와 같은 데이터베이스 객체를 논리적으로 그룹화하는 데 사용됩니다.

CREATE SCHEMA 문을 사용하여 새 스키마를 생성할 수 있습니다.

SQL

CREATE SCHEMA my_schema;
기본적으로 모든 사용자는 public 스키마에 객체를 생성할 수 있습니다. 이전에 생성한 weather 테이블과 cities 테이블은 public 스키마에 있습니다.

새로 만든 my_schema에 테이블을 생성하려면 CREATE TABLE 문에 스키마 이름을 지정해야 합니다.

SQL

CREATE TABLE my_schema.weather (
    city            varchar(80),
    temp_lo         int,
    temp_hi         int,
    prcp            real,
    date            date
);
이와 같이 스키마를 사용하면 같은 데이터베이스 내에서 동일한 이름의 테이블을 여러 개 만들 수 있으며, 사용자나 애플리케이션에 따라 다른 접근 권한을 설정하는 데도 유용합니다.
---

CREATE TABLE cities (
    name            varchar(80) UNIQUE NOT NULL,
    location        point
);

CREATE TABLE weather (
    city            varchar(80) REFERENCES cities (name),
    temp_lo         int,
    temp_hi         int,
    prcp            real,
    date            date
);
이 FOREIGN KEY 제약 조건은 weather 테이블의 city 열에 삽입되는 모든 값이 cities 테이블의 name 열에 이미 존재해야 함을 보장합니다.
